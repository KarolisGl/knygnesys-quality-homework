# Formatting source scope and explicit defaults

The official VILNIUS TECH September-2026 process document, paragraph 18.3, says:

> „Specialiuosius BD rengimo, įforminimo ir pristatymo ginti reikalavimus nustato fakultetai, kurių padaliniai (katedros) parengia metodinius nurodymus.“

Source: https://vilniustech.lt/wp-content/uploads/2026/09/Baigiamuju-darbu-rengimo-ir-gynimo-tvarkos-apraso-nauja-redakcija.pdf?x77629

This delegates detailed requirements to faculties/departments. It does not establish a universal university margin/font specification. The team's faculty/department was not specified; its first page is intentionally editable.

The previously indexed master's-methodology PDF link currently returns the university's HTML 404 page, not a PDF. Its search snippet mentioning Times New Roman and 1.5 spacing is not treated as a verified full-text formatting rule.

Explicit provisional academic layout used for the supplied report:

- A4, portrait.
- Times New Roman, twelve-point body, justified, one-and-a-half line spacing.
- Left thirty millimetres; right ten; top and bottom twenty.
- First-line indent twelve-and-a-half millimetres.
- Black headings; first level fourteen-point, other levels twelve-point.
- Tables ten-point, single-spaced, repeated header, rows not split.
- Automatic contents and page numbers; title page without visible footer.

These are declared layout defaults, not a claim of certification against an unidentified department's current template. Exact faculty-specific compliance remains unverified. If an applicable template differs, change the paragraph styles and page setup and refresh the contents before submission.

Local rendering uses real extracted Times New Roman fonts with a work-local fontconfig file; it does not silently call a substitute Times New Roman. Font/render verification is reported separately from source-applicability verification.
